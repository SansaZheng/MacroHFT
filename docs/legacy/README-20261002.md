# MacroHFT reproduction and methodological experiments

Paper: https://arxiv.org/abs/2406.14537
Official source: https://github.com/ZONG0004/MacroHFT
Pinned source revision: `31e5ef41f93b2aea6e63e6ae2267675c997a8e54`.

## Scope and evidence

The public release supplies ETH data and six pretrained ETH subagents. The first full experiment retrains the hyper-agent, reusing these six checkpoints. This is **not** a from-scratch reproduction of all four markets or eight competing baselines. Published ETH return 39.28% and EarnHFT 18.02% remain literature values until comparable runs finish.

- `paper/MacroHFT-KDD2024-published.pdf`: published paper from the author's NTU website.
- `paper/MacroHFT-KDD2024.pdf`: arXiv version, retained for provenance.
- `results/data-audit.json`: raw-data SHA256, chronological splits, feature checks and preprocessing equivalence.
- `results/official-runtime-and-variants.patch`: changes against the pinned code.
- `results/tests.log`: integration and equivalence checks.
- `results/smoke-*.json`: explicitly limited real-data integration checks, not paper results.
- `results/pipeline-status.json`: server execution status (local copy is a snapshot).
- `results/selection-frozen.json`: validation-selected variant, written before any test evaluation.
- `results/final-summary.json`: created only after all planned training and final test evaluation finish.

## Registered protocol

Use original minute data: train 2022-02-01 through 2023-01-31; validation 2023-02-01 through 2023-05-31; test 2023-06-01 through 2023-10-31. As in the official preprocessing, remove the first 360 rows of each split. Use fee 0.0002, ETH holding size 0.2, 15 epochs, seed 12345, replay capacity 1,000,000, batch size 512, learning rate 1e-4, gamma 0.99, and the released six checkpoints.

Four configurations: reference; action-conditioned retrieval (filter matching actions before selecting five nearest neighbors); demonstration fee aligned from 0.001 to 0.0002; both changes. Train all on seed 12345 and select each checkpoint by full validation return. Freeze the best methodological candidate by validation return. Run the same chosen candidate and reference with seeds 2024 and 42 irrespective of any test results. Then evaluate the six selected checkpoints on test exactly once. Report every seed, mean and sample standard deviation. Stop this predeclared search after these trials, whether or not the paper is surpassed. A failure to improve is a reportable outcome, not grounds for test-driven tuning.

No transaction assumptions are silently improved: the reference retains same-close fills, no explicit slippage, no terminal liquidation fee, and profit divided by the maximum historical cash requirement. Conventional fixed-capital returns are not interchangeable with that return. Treat trading numbers as simulator results.

## Runtime repairs and acceleration

Deep-copy selected state dictionaries; save them directly; fix test checkpoint loading; separate experiment outputs; avoid gradients in frozen experts; replace quadratic cumulative cash accounting with cumulative sums. Keep the original global-batch advantage centering during training. Batched evaluation reproduces one-observation centering. Frozen-expert caching and an array-backed training environment are numerically tested against the original implementations; small floating-point differences can change stochastic training trajectories. Runtime cache can be disabled with `--no_cache`, and the original pandas environment with `--original_environment`.

The original alpha/beta code assignments are retained even though the paper's equation assigns their names differently. The source's 64-dimensional subagent uses 256-wide hidden heads; section 5.4 describes policy dimension 128. These are disclosed discrepancies, not silently repaired scientific settings. The precomputed data does not include its original feature-generation pipeline, so upstream feature causality cannot be fully audited here.

## Commands

Run from this directory with a Python environment containing torch, numpy, pandas, scipy, scikit-learn, pyarrow, gym 0.26.2, tensorboard, pyyaml, joblib, and optionally numba.

```sh
.venv/bin/python scripts/prepare_data.py
.venv/bin/python tests/test_reproduction.py
.venv/bin/python scripts/smoke_train.py --variant reference --fast
.venv/bin/python scripts/run_experiment.py --variant reference --seed 12345
.venv/bin/python scripts/experiment_pipeline.py
```

The initial pipeline runs on `c225:/date/zyy/macrohft-reproduction`. The distributed continuation is configured in `scripts/cluster_plan.json`: it retains all four initial-seed trials on c225 and assigns eight speculative additional-seed trials to c219, c220, c224, c237 and c203, using at most two low-priority, one-thread CPU jobs per additional host. Only the original seed-12345 validation scores choose the candidate. Unselected speculative trials may be stopped after selection; their logs are retained. Six final checkpoints (reference and selected candidate, three seeds each) are evaluated centrally, once. No test data is sent to workers.

New worker environments, code, caches, temporary files and outputs are confined to private project directories under `/date/zyy` or `/data/zyy`, with a 60 GiB free-space preflight. The initial c225 environment reads existing Torch dependencies via a `.pth` file without modifying that environment; running trials retain it. The new hosts use a self-contained Python 3.10 / PyTorch 2.8 CPU environment, with user-site imports disabled and module paths verified. Runtime differences are disclosed. Exact versions and checks are in `results/remote-environment.txt` and `results/cluster/`. All five setup receipts report verified, and eight additional trials have launched. See `paper/workflow/state.md` for the latest verified snapshot.

Do not launch a duplicate pipeline while the recorded process is alive. Completed runs may be reused; an interrupted epoch is not exactly resumable because the upstream trainer does not checkpoint replay, memory, optimizer and RNG state. Archive partial output before restarting a failed run.
